# 📈 AI Stock Price Prediction App

This project is a machine learning and Deep Learning-based stock price prediction system built using **PyTorch** and deployed with **Streamlit**.

## 🚀 Features

* Predict stock prices using ANN model
* Real-time input via interactive UI
* Scaled input handling using StandardScaler
* Clean dashboard interface

## 🧠 Model

* Architecture: Artificial Neural Network (ANN)
* Inputs: Open, High, Low, Adj Close, Volume
* Output: Predicted stock price

## 🛠 Tech Stack

* Python
* PyTorch
* Streamlit
* Scikit-learn

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
